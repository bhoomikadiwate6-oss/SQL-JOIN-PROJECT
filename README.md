# SQL JOIN E-Commerce Project

## 📌 Project Overview

This project demonstrates my practical understanding of SQL JOINs using an E-Commerce database.

I created SQL queries to combine, filter, and analyze data from multiple related tables.

## 🗄️ Database

The project uses the following tables:

- Customers
- Orders
- Order_Items
- Products
- Employees

## 🔗 SQL Concepts Covered

- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- SELF JOIN
- CROSS JOIN
- FULL OUTER JOIN using UNION
- Multiple-table JOINs
- GROUP BY
- HAVING
- COUNT()
- SUM()
- AVG()
- ORDER BY
- LIMIT
- WHERE

## 💼 Business Questions Solved

- Find customers and their orders.
- Find customers who have never placed an order.
- Find customers with more than one order.
- Calculate total spending for each customer.
- Find the highest-spending customers.
- Calculate average order amount.
- Find employees and their managers.
- Find employees reporting to a specific manager.
- Count employees managed by each manager.
- Generate customer-product combinations.

## 🛠️ Tools Used

- MySQL
- MySQL Workbench
- GitHub

## 🎯 Learning Outcome

Through this project, I practiced SQL JOINs and learned how to combine JOINs with aggregate functions, filtering, grouping, and sorting to solve real-world data analysis problems.
